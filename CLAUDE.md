# Dota 2 Meta — контекст проекта

Сайт на GitHub Pages (`main`, корень): https://istrebitelmefa.github.io/Dota2-meta/
Пользователь общается по-русски, интерфейс сайта тоже на русском.

**Деплой после каждого изменения:** пользователь проверяет сайт с телефона, поэтому после каждой правки коммить и пушь сразу в `main` (GitHub Pages собирается ~1–2 мин) и присылай ссылку вида `https://istrebitelmefa.github.io/Dota2-meta/?v=<короткий хэш коммита>` (параметр обходит кэш браузера).

## Что делает сайт
Один файл `index.html` (vanilla JS, без сборки). Вкладки:
- **Связки** — переключатель «Пары»: керри + 5 или 4 + 5. Режим 4 + 5: в команде два игрока с наименьшим GPM (5-ка — самый низкий, 4-ка — второй), SQL с `row_number()`, грузится лениво при выборе (`S.duos45`).
  Керри + 5 — пары героев одной команды на лёгкой линии (`lane_role=1`), керри = выше GPM. Винрейт, W–L, число игр, «синергия» (WR пары минус средний WR героев), сортировка по нижней границе Уилсона.
- **Сборки** — по `purchase_log` (стартовые, ранние, лучшая сборка по времени покупки, ситуативные, таблица всех предметов, лучшие напарники). Фолбэк — итоговый инвентарь `item_0..5`.
- **Варды** — карта `map_740.webp` (из odota/web, карта 7.40) с позициями из `obs_log`/`sen_log` последних 3000 про-матчей периода. Координаты 64..191 → `u=(x-64)/127, v=(191-y)/127` (как у OpenDota). Соседние клетки жадно кластеризуются в «центряки» (средневзвешенный центр), фильтры: тип варда, сторона, время, число точек, тепловая карта.
- **Герои патча** — пик/винрейт в про-матчах + паб-винрейт (ранги 7–8 из `/api/heroStats`).

## Данные
- Всё грузится в браузере из OpenDota API (`https://api.opendota.com/api/`), CORS открыт.
- Текущий патч: последний элемент `/constants/patch` (сейчас 7.41, с 24.03.2026, ~8.9k про-матчей).
- Связки и сборки считаются SQL через `/explorer?sql=` (только про-матчи; паб-данных по связкам у OpenDota нет).
- Константы героев/предметов: `/constants/heroes`, `/constants/items`; картинки с `cdn.cloudflare.steamstatic.com`.
- Кэш ответов в localStorage на 1 час.

## Важно
- Код ещё не проверен на живых данных OpenDota — только на моках (Playwright). Из облачной среды Claude api.opendota.com недоступен, поэтому проверку делает пользователь в браузере.
- Dotabuff/Stratz не используются: у Dotabuff нет API, Stratz требует токен.
